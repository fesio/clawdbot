# Getting Started with Android

Welcome! This guide will help you get the Clawdbot Android app running on your phone.

## 🚀 Quick Start

For detailed step-by-step instructions, see:
- **[Android Quick Start Guide](../../docs/platforms/android-quickstart.md)** (English)
- **[Szybki Start - Android](../../docs/platforms/android-quickstart-pl.md)** (Polski)

## 📱 What You Need

- Android phone (Android 12 / API 31 or higher)
- A computer running the Clawdbot Gateway
- Both devices on the same network (or connected via Tailscale)

## ⚡ Two Ways to Get Started

### Option 1: Use a Pre-built APK (Easiest)
1. Download the latest APK from GitHub releases
2. Install on your phone
3. Connect to your Gateway

### Option 2: Build from Source
1. Install Android Studio
2. Open this folder (`apps/android`) in Android Studio
3. Build and install:
   ```bash
   ./gradlew :app:assembleDebug
   ./gradlew :app:installDebug
   ```
